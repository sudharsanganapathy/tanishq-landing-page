## ✨ Overview

This project is a **Tanishq-inspired jewellery landing page** created as a frontend development assessment.

The goal was to recreate the visual language of a premium jewellery brand while maintaining:

* Elegant typography
* Editorial-style layouts
* Nature-inspired visual elements
* Responsive behaviour
* Reusable React components
* Clean component architecture
* Smooth and modern interactions

The experience is centered around the concept of **natural uncut diamonds inspired by jasmine**, combining traditional South Indian jewellery aesthetics with a contemporary digital experience.

---

## 🎯 Project Objective

The primary objective of this project was to demonstrate the ability to:

* Translate a real-world design into a React application
* Build a premium responsive UI from scratch
* Create reusable and maintainable components
* Structure content separately from presentation
* Implement responsive navigation
* Work with external visual assets
* Build a polished frontend suitable for production deployment

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/tanishq-uncut-landing-page.git
```

### 2. Navigate to the project

```bash
cd tanishq-uncut-landing-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

---

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🔗 External Assets

The project currently references selected external image assets through publicly accessible image URLs.

This keeps the repository lightweight while allowing the browser to load the campaign visuals at runtime.

For production ownership and long-term reliability, these assets can alternatively be moved into:

```text
src/assets/
```

and imported directly into the React components.
